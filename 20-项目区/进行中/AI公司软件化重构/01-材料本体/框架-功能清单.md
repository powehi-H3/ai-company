## 二、L1：文件夹公司（已能用）

### 2.1 三个核心脚本

| 脚本 | 干什么 | 对应规矩/根因 |
|---|---|---|
| `new-project.sh "<项目名>"` | 一键立项：主目录 + 8 工位子目录 + 开场白 + 分配表模板 + 说明模板 + 检查清单 | 规矩一 / R1 |
| `pack-project.sh` | 可交付闸门：打包前检查材料本体在不在，空壳只能叫「骨架包」 | 规矩六 / R2 |
| `archive-project.sh "<项目名>" 完成\|搁置` | 结项归档：打包全部 → 移入已完成/搁置 → 清外围 → 工位回空 | 规矩十九二十 |

### 2.2 五份制度文件（约束行为）

| 文件 | 作用 |
|---|---|
| `00-公司规则.md` | 22 条规矩，公司章程 |
| `09-协作能力清单.md` | 谁能读、谁不能、传话规则、同步约束 |
| `07-根因与通用修复原则.md` | R1~R4，通用修复思想 |
| `08-项目启动与交付标准流程.md` | 8 步标准流程 |
| `06-产出存放规定.md` | 产出落手机目录 |

### 2.3 三个固定模板

| 模板 | 用在哪 |
|---|---|
| `00-通用开场白.md` | 跟任何 AI 开新对话的第一句，固定不变 |
| `00-人员分配表.md` | 谁参与、谁跳过、跳过理由 |
| `00-启动检查清单.md` | 立项后逐项勾选 |

## 三、L2：软件看板（集合体插件 v2.0，已做出来）

**一个入口进去整个公司，内部切换 7 个房间。**

### 3.1 门厅（首页）

- 3 个大数字：进行中 / 已归档 / 规矩通过数
- 7 个房间入口，一键进入

### 3.2 七个房间

| 房间 | 功能 | 数据来源 |
|---|---|---|
| 📄 文档 | **33 份文档集中索引**，按项目分组，标注类型/大小。新写 `00-*.md` 自动收录 | 扫文件系统 |
| 办公区 | 8 个工位 + 状态灯 + 能力边界表（能做/不能） | 读工位目录 |
| 项目区 | 进行中/已完成/已搁置，带进度%和 ZIP 状态 | 读项目目录 |
| 规矩 21 条 | 逐条给状态灯，能机器查的才亮，其余标「人工执行」 | 规则引擎 |
| 会议室 | 决策记录 | 读目录 |
| 档案室 | 6 个柜子 + 8 份员工档案 | 读目录 |
| 工具库 | 4 个脚本分别对应哪条规矩 | 读目录 |

### 3.3 自动化能力

| 功能 | 说明 |
|---|---|
| 状态条 | 输入框上方常驻显示「N 项在跑 · 规矩 X/Y」 |
| 自动刷新 | 每 2 分钟自动重读公司目录 |
| 手动刷新 | 点一下重读 |
| 文档自动索引 | 新文档自动进「文档」房间，不用手动登记 |
