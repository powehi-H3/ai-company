## 一、为什么要装 ADBKeyBoard

**问题**：Android 的 `input text` **不支持非 ASCII 字符**，实测直接抛异常：

```
Exception occurred while executing 'text':
    at com.android.server.input.InputManagerService.onShellCommand
```

**我试过的三条路都失败**：

| 方案 | 结果 |
|---|---|
| `input text "中文"` | ❌ 抛异常崩溃 |
| `input text "\u4e2d\u6587"` | ❌ 当成字面文本 |
| `service call clipboard` | ❌ Parcel 构造失败 |
| `am broadcast clipper.set` | ❌ 无响应 |

**学到的标准解法**（来自 `openatx/uiautomator2` 文档）：

> When `send_keys` is used, it prioritizes using the clipboard.
> If the clipboard interface is unavailable, it will attempt to install and use an auxiliary IME.

**即：装一个辅助输入法，通过广播注入文字。**

## 二、安装 ADBKeyBoard

| 项 | 值 |
|---|---|
| 项目 | `senzhk/ADBKeyBoard`（**1,991 ★**，开源） |
| 版本 | v2.5-dev |
| 大小 | **18,753 B** |
| 下载 | `https://github.com/senzhk/ADBKeyBoard/releases/download/v2.5-dev/keyboardservice-debug.apk` |
| sha256 前 32 位 | `41a8a0996d7397a2390d1ca16a75cb66` |
| 包名 | `com.android.adbkeyboard` |
| IME ID | `com.android.adbkeyboard/.AdbIME` |

### 安装步骤

```sh
# 1. 下载
curl -sL -o /data/local/tmp/adbkb.apk "<上面的链接>"

# 2. 安装
pm install -r /data/local/tmp/adbkb.apk
# → Success

# 3. 启用（注意：enable 不等于设为默认）
ime enable com.android.adbkeyboard/.AdbIME

# 4. 设为默认（必须！否则广播无效）
ime set com.android.adbkeyboard/.AdbIME

# 5. 用完还原
ime set com.sohu.inputmethod.sogouoem/.SogouIME
```

## 四、中文输入的两种广播（都实测可用）

### 方式 1：直接传中文

```sh
am broadcast -a ADB_INPUT_TEXT --es msg "中文测试"
```

✅ 实测成功（`含 中文测试: 1`）

### 方式 2：base64（官方推荐，兼容性更好）

```sh
B64=$(echo -n "中文base64测试" | base64 | tr -d '\n')
am broadcast -a ADB_INPUT_B64 --es msg "$B64"
```

✅ 实测成功（`含 中文base64测试: 1`）

### 其他有用的广播

| Action | 作用 |
|---|---|
| `ADB_CLEAR_TEXT` | 清空输入框 |
| `ADB_INPUT_CODE --ei code 67` | 按键（67=退格） |
| `ADB_EDITOR_CODE --ei code 2` | 编辑器动作（2=发送/前进） |

## 五、代价与限制

| 项 | 说明 |
|---|---|
| **必须切换默认输入法** | ADBKeyBoard 要是当前输入法，广播才生效 |
| **切换瞬间影响打字** | 你正在打字时切换会中断 |
| **用完必须还原** | 否则你打字会变成「无反应」 |
| **需要一个 APK** | 18KB，已装 |

**缓解**：脚本里做「切换 → 投递 → 还原」，整个过程 3~5 秒。

## 六、一个必须记住的坑

**我第一次测试「成功」了，但抓错了界面。**

```
t8.xml 的 package 是 io.github.ccch1mneyyy.dsh_app  ← DSH，不是千问
```

**原因**：执行到一半焦点被 DSH 抢回。

**教训**：**每一步都要验证 `package` 和 `topResumedActivity`，不能只看「有没有找到文字」。**
