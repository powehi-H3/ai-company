## 已完成：软件化控制台 V1

**是什么**：一个 Cordis 网页插件（React + CSS），把公司文件夹变成可交互控制台。

**源码**：`60-工具与备份/插件-ai-company-web/`（在公司文件夹内，已进 GitHub）

**安装 / 卸载 / 入口 / 踩坑记录**：见源码目录里的 `安装说明.md`。

> ⚠️ 入口在**网页版**：`...` → 更多会话视图 → AI公司。不在原生界面。

**功能**：总览 / 项目 / 文档 / 团队 / 制度五个分区；异常置顶、项目分类、文档类型筛选、规矩可检；三层缓存秒开。

**GitHub**：https://github.com/powehi-H3/ai-company
