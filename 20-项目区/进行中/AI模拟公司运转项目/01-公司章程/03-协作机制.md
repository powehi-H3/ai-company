# 协作机制（最重要的一章）

---

## 一、为什么需要"秘书传话"

### 1.1 技术事实

| 能力 | DSH | 其他 AI |
|---|---|---|
| 读别的 AI 的对话 | ✅ 有 root，能读数据库 | ❌ 做不到 |
| 给别的 AI 发消息 | ❌ **没有接口** | ❌ 做不到 |

**结论：AI 之间能"看"，不能"说"。**

### 1.2 所以必须有个人传话

```
DSH 想派活给千问
      ↓
DSH 说给你听
      ↓
你去千问那里打字
      ↓
千问答完了，写在自己的对话里
      ↓
DSH 自己去读
```

**你只在"派活"这一步介入，"收结果"不用你管。**

## 二、标准协作流程（6 步）

### 第 1 步：下发任务

**你说的话（复制粘贴给每个 AI）：**

```
【项目协作说明】

我在同时用几个 AI 一起做这个项目，其中有一个叫 DSH 的助手。
DSH 能读到我们这里的全部对话内容。

所以请你：
1. 结论写清楚、写完整
2. 有明确结论时，用「结论：」开头单独写一段
3. 有不同意见时，直接说"我不同意 X，因为 Y"
4. 不确定的地方，明确说"这里我不确定"

现在开始，任务是：

（这里写任务）
```

**发给：ChatGPT、千问、大肥鱼、豆包、Grok、DSH（每个都要发）**

### 第 2 步：等它们回答

不用管，去干别的。

### 第 3 步：找 DSH 汇总

**你对 DSH 说：**

```
同步一下，然后汇总大家对这个任务的想法
```

DSH 会：
1. 读所有 AI 的回答
2. 对比分析
3. 指出谁说得对、哪里有矛盾
4. 给出执行方向

### 第 4 步：DSH 给你派活单

格式长这样：

```
【执行方向】
采用方案 B，因为……

【分工】
- 豆包：看视频，分析画面
- 千问：写方案文档
- 大肥鱼：写代码
- DSH：汇总验收
```

### 第 5 步：你照着派活

把上面「分工」里的话，复制给对应 AI。

**你对千问说：**

```
按 DSH 的安排，你的任务是：写方案文档。

请按之前的约定：
1. 用「结论：」开头写结论
2. 不确定的地方明说
```

### 第 6 步：找 DSH 验收

**你对 DSH 说：**

```
同步一下，看看大家干得怎么样
```

DSH 读结果后告诉你：
- 谁干得好
- 谁干得不对
- 还差什么
- 能不能验收

---

## 三、你要记住的 4 句话

| 场景 | 对 DSH 说什么 |
|---|---|
| 汇总意见 | `同步一下，汇总大家对这个任务的想法` |
| 派活 | `根据大家的回答，给我一张派活单` |
| 验收 | `同步一下，看看大家干得怎么样` |
| 查历史 | `搜一下我以前在哪说过 XX` |

**就这 4 句，够用了。**

---

## 四、为什么要告诉 AI "DSH 能看到"

你提的这个设计，有三个作用：

| 作用 | 说明 |
|---|---|
| **让它认真写结论** | 知道有人在看，不会糊弄 |
| **让 DSH 好读** | 有「结论：」标记，好提取 |
| **允许说不同意** | 避免所有 AI 都说"好的没问题" |

**这是整个协作机制的关键。** 不告诉它们，它们会写一堆模棱两可的话，DSH 读不出东西。

## 五、常见问题

### Q：能不能让 AI 自己对话，不用我传？

**不能。** 技术上没有通道。

有人说"可以用 API 啊"——那是要花钱买接口，且要自己写程序。而且你明确说了不要 API。

### Q：能不能让 DSH 自动点屏幕发消息？

**能做，但不建议。** 原因：
- App 一改版就废
- 频繁模拟操作会被风控
- 每个 App 要写一套

### Q：那我岂不是很累？

**不累。** 你只做 4 个动作：
1. 发任务（一次，复制粘贴）
2. 找 DSH 汇总（一句话）
3. 派活（复制粘贴）
4. 找 DSH 验收（一句话）

**不用记内容，不用分析，不用检查。**

### Q：豆包读不到怎么办？

豆包的对话没存到手机本地。先多聊几句，再看。读不到就暂时不用它，其他三个够用。

## 六、这套机制的价值

| 传统方式 | 这套机制 |
|---|---|
| 你要记住每个 AI 说过什么 | 不用记，DSH 能搜 |
| 你要自己对比谁说得对 | DSH 对比 |
| 你要自己检查干得对不对 | DSH 验收 |
| 换个 AI 就得重新解释背景 | 资料都在文件夹里 |
| 上下文一长 AI 就忘 | 不依赖 AI 记忆 |

**核心：把"记忆"和"判断"从你身上，转移到系统和 DSH 身上。**
