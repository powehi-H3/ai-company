# 工具说明

## 已安装的工具

| 工具 | 位置 | 用途 |
|---|---|---|
| 对话同步器 | `/root/日常任务区/multi-ai-bridge/sync.sh` | 读所有 AI 对话 |
| 全文检索 | `/root/日常任务区/multi-ai-bridge/search.sh` | 搜历史对话 |
| 知识库 | `/root/日常任务区/ai-memory/` | 存所有对话 |

## 常用命令

```bash
# 同步最新对话
cd ~/日常任务区/multi-ai-bridge && ./sync.sh

# 搜索
./search.sh "关键词"
./search.sh "关键词" --app qwen
./search.sh "关键词" --role User
```

## 注意

这些工具在 DSH 的 Linux 环境里，不在手机存储里。
需要 DSH 帮你跑，你直接说"同步一下"就行。
