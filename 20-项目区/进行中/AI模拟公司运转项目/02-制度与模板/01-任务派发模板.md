# 任务派发模板

**用法：** 复制下面整段，把 `（这里写任务）` 替换成实际任务，发给每个 AI。

---

## 模板 A：新项目启动（发给所有 AI）

```
【项目协作说明】

我在同时用几个 AI 一起做这个项目，其中有一个叫 DSH 的助手。
DSH 能读到我们这里的全部对话内容。

所以请你：
1. 结论写清楚、写完整，不要只说"建议这样做"就完事
2. 有明确结论时，用「结论：」开头单独写一段
3. 有不同意见时，直接说"我不同意 X，因为 Y"
4. 不确定的地方，明确说"这里我不确定"

项目名称：（项目名）

现在开始，任务是：

（这里写任务）
```

---

## 模板 B：派活（DSH 给了分工后，发给对应 AI）

```
【任务派发】

按项目整体安排，你的任务是：

（这里写具体任务）

请按约定：
1. 用「结论：」开头写结论
2. 不确定的地方明说
3. 完成后告诉我你做了什么、结果如何
```

---

## 模板 C：验收追问

```
【验收反馈】

DSH 看了你的产出，有几个问题：

（这里写问题）

请针对这几点修正后重新回答。
```

---

## 模板 D：收集能力自述

```
请用 200 字以内介绍：

1. 你最擅长处理哪类任务？
2. 你有哪些明确的局限（做不到什么）？
3. 如果让你在一个多 AI 协作项目里担任一个角色，你希望是什么角色？为什么？
```
