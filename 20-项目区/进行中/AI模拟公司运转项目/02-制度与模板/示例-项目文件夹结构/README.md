# 示例：项目文件夹结构

**这是命名示范，不是真实项目。**

---

## 每个工位下，一个项目一个文件夹

```
10-办公区/02-分析部-ChatGPT/
├── 职责卡.md                ← 固定，说明我是谁
├── 比如项目1/               ← 项目文件夹（用项目全名）
│   ├── README.md           ← 这个文件夹放什么
│   └── 20261115-分析.md    ← 具体产出（日期-内容）
└── 比如项目2/               ← 另一个项目
    └── README.md
```

---

## 命名要点

| 要 | 不要 |
|---|---|
| 用项目全名 | 用"项目1""项目2" |
| `AI模拟公司运转项目` | `模拟公司` |
| 不加日期前缀 | `20261115-模拟公司` |
| 不加版本号 | `模拟公司-v2` |

---

## 为什么

**文件夹名本身就是信息。**

看到 `AI模拟公司运转项目`，立刻知道是什么。
看到 `项目1`，还要打开才知道。

**所以：文件夹名字就是思路。**
