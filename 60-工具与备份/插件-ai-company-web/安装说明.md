# AI 公司控制台 · 网页插件 安装说明

> 版本 1.0.0 · 2026-11-17
> 技术路线：Cordis 插件（React + CSS），与 dsh-context 同款。

---

## 一、这是什么

把「AI 公司」从文件夹变成一个**可交互的网页控制台**。

- 5 个分区：总览 / 项目 / 文档 / 团队 / 制度
- 深色卡片、2×2 指标、彩色状态、原地展开
- 三层缓存，点开秒进

**和旧的原生胶囊插件是完全不同的两套东西：**

| | 旧原生插件（已卸载） | 本插件（当前） |
|---|---|---|
| 渲染 | Flutter JSON | React + CSS |
| 位置 | dsh-go 原生界面 | **网页模式** |
| 样式自由度 | 40 个固定组件 | 任意 CSS |

## 二、安装（在手机上执行）

### 1. 装依赖（一次性，需联网）

```bash
cd /opt/dsh
npm install --no-save \
  @deepseek-ai/dsh-client-ui-primitives@0.2.2-rc.1 \
  react@18.3.1 react-dom@18.3.1 \
  clsx anser katex shiki @shikijs/langs simple-icons \
  @deepseek-ai/dsh-client-store@0.2.2-rc.1 \
  @deepseek-ai/dsh-util-code-language@0.2.2-rc.1 \
  @deepseek-ai/dsh-util-workspace-path@0.2.2-rc.1
```

依赖清单（primitives 的隐式依赖）：
`clsx`、`anser`、`katex`、`shiki`、`@shikijs/langs`、`simple-icons`、
`mdast-util-*`、`micromark-*`、`@deepseek-ai/dsh-client-store`、
`dsh-util-code-language`、`dsh-util-workspace-path`

### 2. 把插件放到工作区

把本目录（`插件-ai-company-web/`）复制到：

```
/root/插件工作区/ai-company-web/
```

即：`package.json`、`cordis.patch.yml`、`lib/index.js`、`lib/client.js` 四个文件。

### 3. 安装到 web profile

```bash
cd /root/.dsh/profiles/web
pnpm add "file:/root/插件工作区/ai-company-web"
```

### 4. 确认注册（两处都要有）

**a) `package.json` 的 bundles：**
```json
"dsh": { "profile": { "bundles": [ ..., "local-ai-company-web" ] } }
```

**b) `cordis.patch.yml`：**
```yaml
- id: local-ai-company-web
  name: local-ai-company-web
```

### 5. 重启引擎

App → 引擎 → 重启引擎。

## 三、怎么打开（重要，之前一直找错地方）

**入口不在原生界面，也不在输入框上方。**

正确路径：

```
网页版对话 → 顶部标签栏 → 「...」→ 更多会话视图 → 「AI公司」
```

菜单里会有三项：`上下文`、`AI公司`、`编队`。

进入网页模式：
- App 左上角菜单 → 切换到网页界面
- 或：设置 → 界面 → 网页

## 四、文件说明

| 文件 | 作用 |
|---|---|
| `package.json` | 包声明 + `dsh.client`（platform=web, immediately=true）+ exports |
| `cordis.patch.yml` | bundle patch，`- insert:` 一行 |
| `lib/index.js` | **宿主半侧**（Node）：读公司目录，注册 HTTP 路由 `/ai-company/*` |
| `lib/client.js` | **浏览器半侧**（React）：注册 `conversation.view` 槽位，渲染 UI |

### 关键技术点（踩过的坑）

1. `package.json` 必须有 `"type": "module"` 和 `exports["./client"]`，否则网页版找不到 client bundle。
2. `dsh.client` 必须有 `"immediately": true`。
3. 宿主侧访问服务必须 `ctx.inject(['webServer'], ...)`，服务名是 `webServer`（不是 `server`），注册 API 是 `webServer.register({kind,path,handler})`。
4. client.js 必须写成 `window.__ModuleLoader__.load({ id: <包名>, factory })`，id 等于包名。
5. 注册视图必须有 `locale` 字段：`slots.register({name, id, order, locale, label})`。
6. **根节点视图必须写 `v: 2`**，否则 badge/accordion/segmented 等 v2 组件全部不认识（曾因此 15 个组件报错）。
7. `tabs` 的后代始终计入 JSON 预算，分区导航用 `segmented` + 重新生成树。

## 五、数据缓存机制

解决"每次打开都要读取"：

1. **引擎启动预热**：宿主 `apply()` 里调 `collectCached()`，启动时扫一次。
2. **宿主 60 秒缓存**：`collectCached()` 内 `CACHE_TTL = 60s`，实测第二次 0ms。
3. **浏览器模块缓存**：`DATA_CACHE`，切走再回来不发 HTTP。

「刷新」按钮传 `force=1` 强制重扫。

## 六、卸载

```bash
cd /root/.dsh/profiles/web
dsh plugin --profile web remove local-ai-company-web
```

同时从 `package.json` 的 bundles 和 `cordis.patch.yml` 里删掉对应条目，重启引擎。
