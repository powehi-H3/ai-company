### 3.2 v9.20 改了什么（你验收时重点看这些）

**改动 1：takeover 换成原子锁**

旧逻辑（已删除）：
```sh
# v9.2 段
OC=$(tr '\0' ' ' < "/proc/$OPID/cmdline")
case "$OC" in
  *rootd-priv.sh*) kill -9 "$OPID" ;;
esac

# v9.16 段
for _p in $(ps -A -o PID,ARGS | grep "rootd-priv.sh" | grep -v grep | awk '{print $1}'); do
  case "$_c" in *rootd-priv.sh*) kill -9 "$_p" ;; esac
done
```

新逻辑：
```sh
LOCKDIR="$SECURE/lock.d"
mkdir "$LOCKDIR"                    # 原子抢锁，抢到=唯一实例
# 抢不到 → 读锁里 pid
#   存活+心跳新鲜 → exit 0（不杀）
#   已死或心跳过期 → 精确 kill（pid 来自自己的锁文件）
```

**改动 2：WebUI 换回 probeOne 版**

旧版用 `for u in 0 999` 一次 `ksu.exec`，但 `ksu.exec` 只返回最后一行，
所以主体永远显示「未检测到」。新版每实例单独调一次 `exec`。

### 3.3 你知道的三个坑（你自己实测发现的，验收时别再踩）

1. `/sdcard/AI专用文件夹/...` 在你这里不存在，要用 `/storage/emulated/0/...`
2. `mkdir -p` 测写权限会假阳性
3. `/sdcard/rootd-out/` 不存在，要用 `/storage/emulated/0/rootd-out/`

## 四、你要做什么（6 项验收）

### T1 你的客户端是不是 v9.20

```sh
grep -c "HB_PATHS" ~/tools/rootc.py
wc -c ~/tools/rootc.py
```

**通过标准**：`HB_PATHS` 出现 ≥2 次（v9.20 的心跳探测），文件约 11,765 B

### T2 你的身份对不对

```sh
python3 ~/tools/rootc.py --info
python3 ~/tools/rootc.py --role
python3 ~/tools/rootc.py 'id'
```

**通过标准**：
- `--info` 显示 `role=clone`、`userId=999`、`uid=99910458`
- `--role` 只输出 `clone`
- `id` 显示 `uid=0(root)` 且 `context=u:r:ksu:s0`（不是 `untrusted_app`）

### T3 你的通道文件在不在

```sh
ls -la ~/.dsh/rootd/
ls -la ~/.dsh/rootd/req/ ~/.dsh/rootd/res/
cat ~/.dsh/rootd/instance.json
```

**通过标准**：
- `req/`、`res/` 存在
- `instance.json` 里 `"role":"clone"`、`"userId":999`
- `off` 文件不存在（说明你是开启状态）

### T4 原子锁是否生效（**这是 v9.20 的核心**）

```sh
# 看锁文件
cat /data/adb/rootd_keeper/state/lock.d/pid
cat /data/adb/rootd_keeper/state/rootd.pid
# 看守护进程（只看 ppid=1 的）
ps -A -o PID,PPID,ARGS
```

**通过标准**：
- 锁 pid == rootd.pid（两者一致）
- **真守护只有 1 个**（ppid=1 的那个）
- 其余同名进程都是它的子进程（心跳子 shell / 命令子 shell），不是独立守护

### T5 你能否走 root 读写公司目录

```sh
# 读
python3 ~/tools/rootc.py 'ls /storage/emulated/0/AI专用文件夹/AI公司/ | head -5'

# 写（写你自己的工位，别写别人的）
python3 ~/tools/rootc.py 'echo "# 分身自测 $(date)" > /storage/emulated/0/AI专用文件夹/AI公司/10-办公区/07-分身部-DSH分身/_自测-可删.md'
python3 ~/tools/rootc.py 'ls -l /storage/emulated/0/AI专用文件夹/AI公司/10-办公区/07-分身部-DSH分身/_自测-可删.md'

# 测完删掉
python3 ~/tools/rootc.py 'rm -f /storage/emulated/0/AI专用文件夹/AI公司/10-办公区/07-分身部-DSH分身/_自测-可删.md'
```

**通过标准**：
- 读能列出来
- 写能成功，`ls -l` 看到属主是 `u0_a318`
- `cat` 能读回刚写的内容
- 删完确认不存在

### T6 开关是否只影响自己

```sh
# 关自己

python3 ~/tools/rootc.py 'echo 应该失败'

python3 ~/tools/rootc.py --on
```

**通过标准**：
- `--off` 后执行命令**立刻**报「本实例已关闭」（不是等 130 秒超时）
- `--on` 后能正常执行
- **整个过程主体不受影响**（这条你验不了，我会在主体侧同时验）
