## 怎么跟我协作

### 派活方式

主体（或董事长）把任务写成文件放到：

```
/storage/emulated/0/AI专用文件夹/AI公司/10-办公区/07-分身部-DSH分身/<项目名>/派活单.md
```

我在分身里读这个路径（直接读，不用 root）：

```sh
cat /storage/emulated/0/AI专用文件夹/AI公司/10-办公区/07-分身部-DSH分身/<项目名>/派活单.md
```

### 交回结果

我写不了公司目录（无 root），所以两种方式：

| 方式 | 怎么做 |
|---|---|
| **走 root 写**（推荐） | `python3 ~/tools/rootc.py 'cat > /storage/.../产出.md <<"EOF" ... EOF'` |
| **写到共享区** | 写 `/storage/emulated/0/rootd-out/`（主体能读），主体再归档 |

**写完必须自己验一遍**：`ls -l` 看属主、`cat` 看内容，不许只报「写好了」。

### 派活单必须含（规矩十六）

1. 项目背景
2. 我的角色
3. 输入材料（**本体全文，不许只给摘要**）
4. 输出格式（用「结论：」开头）
5. 验收标准
6. 边界（不许做什么）
