# 会议室

**这里放跨项目会议记录、正式决策和复盘记录。** 会议纪要是过程与决策证据；具体项目的执行状态仍以项目状态文件为准。

## 目录结构

按月份归档，例如 `2026-11/`。当前已有记录：

- `20261116-DSH分身入职报告.md`
- `20261116-分身能力实测回答.md`
- `20261116-分身能力确认清单.md`
- `20261116-给分身的原话.md`

## 适用规则

- 跨项目、组织级会议和正式决策放这里。
- 单一项目内部的技术讨论、测试过程和任务记录优先放项目目录。
- 会议记录不得替代项目需求、决策和状态文件；形成正式决定后，应同步更新对应项目的权威文件。
- 文件命名：`YYYYMMDD-主题或会议类型.md`。

## 维护要求

新增或移动记录后，同步更新本 README 的目录索引。不得把“当前目录索引为空”写成仓库事实，必须以实际 Git tree 为准。
