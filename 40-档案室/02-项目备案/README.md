## 归档规则

- 已完成项目的正式源文件应保留在 `20-项目区/已完成/<项目名>/`。
- 归档包是否另存于本目录，按项目归档决策执行；不得仅为满足“双份存储”而制造未经验证的重复副本。
- 归档前必须验证压缩包完整性、文件清单和哈希；归档验证失败时不得删除源文件。
- 同一归档包应有唯一权威副本位置，并在项目清单中登记路径、版本、日期和 SHA-256。
