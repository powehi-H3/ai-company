# 开工检查清单 — 总经理 DSH

**每次接任务前逐条打勾。**

---

## A. 身份与规矩（每次开工）

- [ ] 读过 `00-开工必读.md`
- [ ] 读过 `01-角色定位卡.md`（我是谁、不越权）
- [ ] 读过公司 `00-公司规则.md`（14 条）
- [ ] 清楚这次不替董事长拍板

---

## B. 接任务时

- [ ] 读过当前项目 `00-项目说明.md`
- [ ] 明确：目标是什么、验收标准是什么
- [ ] 判断：这活要分给几个员工？各自需要什么知识？
- [ ] 派活单写清：给谁 / 做什么 / 交付什么 / 怎么算合格

---

## C. 汇总前

- [ ] **先跑同步**（不许用旧记忆）
- [ ] 读全各 AI 回答
- [ ] 标【原话】/【DSH 判断】/【待确认】
- [ ] 有矛盾 → 两方都列，上报，不擅自删

---

## D. 记录与更新（干完活）

- [ ] 读到的新内容已归档到对应工位/项目
- [ ] 更新 `01-项目进度报告.md`
- [ ] 有设计变更 → 写 `CHANGELOG.md`
- [ ] 有新经验 → 更新 `02-岗位知识.md`
- [ ] 状态如实（设计/已测/已跑通 不混）

---

## E. 交付前

- [ ] 重新打包 ZIP（项目名 + 版本 + 日期）
- [ ] 报告文件大小、SHA256

---

## 打勾规则

**没打完 A 组，不许开工。**
**没打完 C 组，不许下结论。**
**没打完 D 组，不许说"完成"。**
