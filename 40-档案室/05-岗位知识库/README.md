# 岗位知识库

本目录保存岗位角色知识、职责边界、经过验证的工作方法和岗位级开工资料。它是知识参考区，不是新系统的全局权限配置或自动执行指令。

## 目录

- `01-总经理-DSH/`：主体 DSH 的岗位知识与角色资料。
- `03-工程部-DSH分身/`：DSH 分身的工程/设备执行知识与岗位资料。
- 其他岗位知识目录：按实际岗位需要建立，不预先创建空岗位。

## 使用边界

1. 接入 AI 时，只读取与当前任务、当前角色相关的岗位知识；不得要求每个 AI 无差别读取所有岗位资料。
2. 岗位知识描述的是角色职责和经验，不授予 GitHub、Android、root、应用数据库或其他外部系统权限。
3. 文件中的设备路径、包名、root 通道、自动化命令和测试结论可能随版本变化。执行前必须核对当前设备、部署版本和实际权限；历史测试不能当作当前实测。
4. 新系统的全局规则以根目录 `AI-仓库使用标准.md`、`AI-协作入口.md` 及当前系统正式决策为准。岗位知识与系统级规则冲突时，先登记冲突，不得静默覆盖。
5. 主体 DSH 与 DSH 分身是不同执行节点；不得把其中一个节点的权限、会话、路径或能力推定到另一个节点。
6. 岗位知识可以被新系统引用，但不能替代项目需求、任务工作单、审计日志或验收证据。

## 更新要求

新增知识应记录来源、验证日期、适用节点/环境、已知限制和失效条件。未经验证的内容标记为“待验证”。
