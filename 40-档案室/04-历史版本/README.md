# 历史版本

**旧版本文件备份，防止误删。**

---

## 什么时候用

| 情况 | 做法 |
|---|---|
| 要改重要文件 | 先把旧版拷到这里 |
| 删文件前 | 先移到这里，不要直接删 |
| 项目版本迭代 | 旧 ZIP 移到这里 |

---

## 命名

```
<原文件名>-<日期>.bak

例：
00-项目说明.md-20261115.bak
AI模拟公司运转项目-v1.0-20261115.zip
```

---

## 清理

**不要永久堆积。**

| 时间 | 动作 |
|---|---|
| 3 个月内 | 保留 |
| 3-12 个月 | 可考虑清理 |
| 1 年以上 | 确认无用后删 |
